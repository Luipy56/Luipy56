# Hi, I'm Yoel, also known as Luipy

**DevOps, Systems & Software Engineer at AMVARA**

I build and operate reliable infrastructure, self-hosted services, web solutions, automation tools, and open-source systems.

My work is centered around **Linux, containers, scripting, web development, infrastructure operations, and practical AI integrations**. I care about systems that are understandable, reproducible, auditable, and straightforward to maintain.

While I have a preferred technology stack, I am not tied to specific tools. I adapt technologies, architectures, and workflows to the actual needs of each project.

Based in **Badalona, Catalonia**.

## Selected projects

### [Ultron](https://github.com/Luipy56/ultron-redmine)

A custom Discord bot and operational assistant integrated with Redmine.

Ultron connects project-management data, scheduled reports, user interactions, and optional LLM processing to simplify team workflows and make relevant information easier to access.

`Python` `Discord` `Redmine` `LLM Integration` `Docker`

### [Agent Bot One](https://github.com/Luipy56/agent-bot-one)

A custom agent focused on server administration, maintenance, troubleshooting, and development tasks.

The project explores how task-specific agents can assist with infrastructure operations while keeping their actions understandable, controlled, and aligned with real administrative workflows.

`AI Agents` `Systems Administration` `Automation` `Infrastructure`

### [KM0 Web](https://github.com/Luipy56/km0-web)

A multilingual marketing website built with Astro and Tailwind CSS, packaged with Docker and served through Nginx.

The project includes responsive frontend development, internationalization, containerized deployment, reverse-proxy configuration, and operational documentation.

`Astro` `TypeScript` `Tailwind CSS` `Docker` `Nginx` `i18n`

### [LdeLuipy Website](https://github.com/Luipy56/LdeLuipy)

My personal web hub for projects, documentation, services, experiments, and useful links.

It includes static pages, interactive web experiences, PHP components, progressive web application features, and projects built using different frontend approaches.

`HTML` `CSS` `SCSS` `JavaScript` `PHP` `PWA`

### [Betterclip](https://github.com/Luipy56/betterclip)

A lightweight clipboard-history utility for Linux desktops.

Betterclip stores recent clipboard entries and provides a searchable interface through Rofi, allowing users to quickly recover and reuse previously copied text using a configurable keyboard shortcut.

`Python` `Linux` `Rofi` `Desktop Automation`

### [MC Texture Viewer](https://github.com/Luipy56/mc-texture-viewer)

An embeddable 3D web viewer for Minecraft-style models.

It supports glTF, GLB, OBJ, and MTL assets, dynamic texture-pack replacement through ZIP uploads, lighting, shadows, automatic rotation, and fallback textures.

`JavaScript` `Three.js` `Web Components` `3D Rendering`

## How I approach systems

> Automate what repeats, document what matters, and keep complexity proportional to the problem.

I prefer solutions that can be understood, tested, reproduced, and maintained without relying on hidden knowledge.

Good infrastructure should not only work today. It should remain understandable when something fails months later.

Good software should not only meet its current requirements. It should also be clear enough to evolve when those requirements change.
